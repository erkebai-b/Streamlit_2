# Streamlit_2 — Multipage App

The official Streamlit ["Create a multipage app"](https://docs.streamlit.io/get-started/tutorials/create-a-multipage-app) tutorial, restyled with an Apple-inspired design.

- `Hello.py`: entrypoint / home page
- `pages/`: Plotting, Mapping and DataFrame demos (sidebar navigation is built from this folder)
- `style.py`: shared stylesheet and helpers
- `.streamlit/config.toml`: theme

Run locally: `pip install -r requirements.txt && streamlit run Hello.py`
